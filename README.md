# 发票助手 🧾

本地发票统计工具：解析电子发票 PDF 的**商品明细**，输出金额 / 税额 / 价税合计，
带**桌面版**、**网页版**和**命令行版**三种用法。数据不出本机。

## 界面（桌面版 / 网页版通用）

```
┌───────────────┬──────────────────────────────┐
│ 文件           │  文件名 —— 缩放 ▬▬▬▬▬▬ 100% │  ← 右上：发票原件
│ [＋选择文件]   │  ┌──────────────────────┐    │     滚轮缩放 / 拖动平移
│ [全部加入]     │  │   (PDF 高清渲染)      │    │     滑块调缩放 25%~400%
│ [全部移出]     │  │   ⇕ 横竖滚动条可用     │    │
│ [全部删除]     │  └──────────────────────┘    │
│                ├──────────────────────────────┤
│ · 文件1 报销 51│  报销明细 46 项               │  ← 右下：整个都是明细
│   移出 ×       │  金额 1603.66 税 103.56 合计…│
└───────────────┴──────────────────────────────┘
```

- **启动**：先弹约 3 秒的开机动画（蓝色 ¥ 先压扁再弹回），动画期间后台预加载解析引擎，**单击（或回车/空格）可跳过**，动画结束即可用
- **窗口**：默认 1080×720 居中，右上角 ⛶ 可最大化，也可自由拉伸（最小 880×560）
- **左**：只用「＋选择文件」手动加 PDF（不扫文件夹、不自动加载），单击看原件，点「加入 / 移出 / ×」管理报销清单；也支持把桌面上的 PDF 直接拖进列表，「全部删除」只清列表不删磁盘文件（带白底确认框）
- **右上**：发票原件纯看图 —— 滚轮缩放、按住拖动、横竖滚动条、缩放滑块；显示当前文件名，打不开时红字提示
- **右下**：报销明细表（名称 / 规格 / 数量 / 单价 / 金额 / 税率 / 税额 / 价税合计），KPI 合计卡片，支持按商品汇总、**价格含税**、导出 CSV、**生成 Excel 报告**；**点明细里任意一格，右上就显示这张发票的原件**
- **⚙ 设置**：默认发票目录、报告保存目录、价格口径、重置默认设置
- **🕘 历史记录**：顶栏按钮切换，左侧变成**按天分类**的日期列表（可上下滑动），
  点某天 → 左下显示当天发票，点某张 → 右上照常预览，右下照常实时合计；
  只记**加入报销成功**的发票，按“加入的那天”分组，存本地 JSON **跨重启保留**，
  点「加入」可重新放进报销清单，「清空」一键清除历史（不动磁盘 PDF）
- **默认目录 =「下载」**：首次使用时，选文件对话框和报告保存路径都落在
  `C:\Users\<用户名>\Downloads`（按 Windows「下载」文件夹的真实位置解析，
  被移动过也能找到；没有就自动创建）

## 命令行版

```bat
py 发票统计工具.py                :: 统计当前文件夹
py 发票统计工具.py "D:\其他发票"   :: 统计指定文件夹
py 发票统计工具.py "D:\发票归档" -r :: 递归子文件夹
```

输出两份 CSV：

- `发票统计_时间.csv`：发票级，含「商品摘要」列
- `报销商品明细_时间.csv`：商品级，每行一个商品，末行合计

## 解析说明

明细表格按 PDF 内的**文字坐标**还原（项目名称 / 规格型号 / 单位 / 数量 / 单价 /
金额 / 税率 / 税额），不依赖文本流顺序，因此换行折断的名称、多行规格都能正确拼回。
每张发票自动核对「明细金额合计 == 票面金额」，不一致时在备注标注。

已在 27 张发票上验证：解析失败 0、明细 46 行，
金额 1603.66 + 税额 103.56 = 价税合计 1707.22，与逐张核对一致。

> 仅支持有文字层的电子发票 PDF，暂不支持图片/扫描件。

## 价格含税口径

发票上的「金额」默认**不含税**（与票面一致，直接使用）。右下工具条的
「**价格含税**」按钮或 ⚙ 设置里可以切换成含税口径，切换后按税率反推：

```
不含税金额 = 含税价 ÷ (1 + 税率)
税额       = 含税价 − 不含税金额
价税合计   = 含税价
```

27 张测试发票的两套口径（供核对）：

| 口径 | 金额(不含税) | 税额 | 价税合计 |
|------|------------:|-----:|--------:|
| 不含税（默认） | 1603.66 | 103.56 | 1707.22 |
| 含税反推 | 1511.12 | 92.54 | 1603.66 |

## 重新打包 exe

```bat
:: 桌面版 → distqt\发票助手.exe（裁剪后约 46MB，图标为蓝色 ¥）
打包桌面版.bat

:: 网页版（约 40MB）
py -m PyInstaller --onefile --noconsole --name 发票助手 ^
   --add-data "index.html;." --add-data "发票解析.py;." 发票助手.py
```

桌面版打包用 `buildqt\发票助手Qt.spec`：排掉 openpyxl 的可选重依赖
（numpy / pandas / scipy / PIL / lxml / matplotlib）和用不到的 Qt 模块
（Quick / Qml / Pdf / Network / OpenGL / `opengl32sw.dll`），
从 130MB 降到约 46MB。
