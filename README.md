# 发票助手 🧾

本地发票统计工具：解析电子发票 PDF 的**商品明细**，输出金额 / 税额 / 价税合计，
带**桌面版**、**网页版**和**命令行版**三种用法。数据不出本机。

## 下载

到 [Releases](https://github.com/wangbq666/fapiao-helper/releases)：

| 资产 | 说明 |
|------|------|
| `fapiao-helper-desktop-v1.1.exe` | **桌面版**（PySide6，推荐）：独立窗口，PDF 直接渲染 |
| `fapiao-helper-v1.0.exe` | 网页版：双击后自动打开浏览器 |

两个都免安装、免 Python。

## 界面（桌面版 / 网页版通用）

```
┌───────────────┬──────────────────────────────┐
│ 文件           │  文件名 —— 缩放 ▬▬▬▬▬▬ 100% │  ← 右上：发票原件
│ [📂选择文件夹] │  ┌──────────────────────┐    │     滚轮缩放 / 拖动平移
│ [＋选择文件]   │  │   (深色画布看图)      │    │     滑块调缩放 25%~400%
│ [全部加入]     │  │   ⇕ 横竖滚动条可用     │    │
│ [全部移出]     │  └──────────────────────┘    │
│                ├──────────────────────────────┤
│ · 文件1 报销 51│  报销明细 46 项               │  ← 右下：整个都是明细
│   移出 ×       │  金额 1603.66 税 103.56 合计…│
└───────────────┴──────────────────────────────┘
```

- **左**：选文件夹只列文件（不自动解析），单击看原件，点「加入 / 移出 / ×」管理报销清单；也支持把桌面上的 PDF 直接拖进列表
- **右上**：发票原件纯看图 —— 滚轮缩放、按住拖动、横竖滚动条、缩放滑块，按当前缩放向服务端取高清图
- **右下**：报销明细表（名称 / 规格 / 数量 / 单价 / 金额 / 税率 / 税额 / 价税合计），KPI 合计卡片，支持按商品汇总、导出 CSV

## 命令行版

```bat
py 发票统计工具.py                :: 统计当前文件夹
py 发票统计工具.py "D:\其他发票"   :: 统计指定文件夹
py 发票统计工具.py "D:\发票归档" -r :: 递归子文件夹
```

输出两份 CSV：

- `发票统计_时间.csv`：发票级，含「商品摘要」列
- `报销商品明细_时间.csv`：商品级，每行一个商品，末行合计

## 源码结构

| 文件 | 说明 |
|------|------|
| `发票解析.py` | 解析核心：抬头 + 按 PDF 文字坐标还原商品明细列 |
| `发票助手Qt.py` | **桌面版**（PySide6 + PyMuPDF，独立窗口） |
| `发票助手.py` | 网页服务端（本地 HTTP，端口 8765，`FP_PORT` 可改） |
| `index.html` | 网页版前端单页界面 |
| `发票统计工具.py` | 命令行版 |
| `使用说明.md` | 详细使用说明 |

桌面版预览用 PyMuPDF 直接渲染进 `QGraphicsView`（滚轮缩放 / 按住拖动 /
原生滚动条 / 缩放滑块），后台 `QThreadPool` 解析不卡界面。

## 解析说明

明细表格按 PDF 内的**文字坐标**还原（项目名称 / 规格型号 / 单位 / 数量 / 单价 /
金额 / 税率 / 税额），不依赖文本流顺序，因此换行折断的名称、多行规格都能正确拼回。
每张发票自动核对「明细金额合计 == 票面金额」，不一致时在备注标注。

已在 27 张发票上验证：解析失败 0、明细 46 行，
金额 1603.66 + 税额 103.56 = 价税合计 1707.22，与逐张核对一致。

> 仅支持有文字层的电子发票 PDF，暂不支持图片/扫描件。

## 重新打包 exe

```bat
:: 桌面版（约 130MB，含 PySide6 + PyMuPDF）
py -m PyInstaller --onefile --noconsole --name 发票助手Qt --distpath distqt 发票助手Qt.py

:: 网页版（约 40MB）
py -m PyInstaller --onefile --noconsole --name 发票助手 ^
   --add-data "index.html;." --add-data "发票解析.py;." 发票助手.py
```
